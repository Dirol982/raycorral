# mosaicist.com — ускорение без смены дизайна

Готовые правки для Webflow. Фоновое видео и аудиоплеер **сохранены**: выглядят и работают как раньше, но грузятся в разы легче.

- Ускоренная копия сайта: https://dirol982.github.io/raycorral/mosaicist/site/
- Текущая версия для сравнения: https://dirol982.github.io/raycorral/mosaicist/site-before/

## Что было не так

| Проблема | Что происходило |
|---|---|
| Фоновое видео на первом экране | 4K (3840 px), 52 МБ, одинаково на телефоне и компьютере |
| Видео-тур по объекту на главной | 4K, 142 МБ, со звуковой дорожкой, хотя играет без звука; начинал качаться сразу при загрузке страницы |
| Видео открывались через hls.js | обычный MP4 читался как потоковый плейлист, и браузер тянул файл целиком; за 20 секунд на главной уходило ~72 МБ |
| Аудиоплеер SoundCloud | на каждой из 27 страниц при входе грузились скрипт и плеер SoundCloud (~1,3 МБ), даже если музыку не включали |
| 7 скриптов в `<head>` без `defer` | загрузчик шрифтов, hls.js, GSAP, Lenis блокировали первую отрисовку |
| Ошибка в коде | у тега `Draggable.min.js` нет `>`: браузер проглатывает следующий скрипт (анимацию появления контента), и он не работает |

## Что в папке

| Путь | Назначение |
|---|---|
| `media/` | облегчённые видео: `hero-*` (первый экран) и `tour-*` (тур), 1080p и 720p в H.264 и AV1, кадры-постеры |
| `webflow/bunny-background.html` | замена скрипта `initBunnyPlayerBackground` (фоновое видео) |
| `webflow/soundcloud-embed.html` | замена Embed аудиоплеера (`spotify_embed`) |
| `webflow/head-code.html` | подключение шрифта без загрузчика WebFont |
| `original/` | исходный код плеера и видео, снятый с сайта, для отката |
| `tools/build-site.py` | сборка демо-копий |

## Установка в Webflow (≈ 1 час)

> Сначала резервная копия: **Site settings → Backups → Create backup**.

### 1. Видео
1. Загрузите файлы из `media/` в хранилище Bunny (то же, где лежат текущие ролики, `mosaicist.b-cdn.net`).
2. На блоке видео первого экрана (**`data-bunny-background-init`**) в **Custom attributes** добавьте:
   - `data-src-desktop` → `…/hero-1080.mp4`
   - `data-src-mobile` → `…/hero-720.mp4`
   - `data-src-desktop-av1` → `…/hero-1080-av1.mp4`
   - `data-src-mobile-av1` → `…/hero-720-av1.mp4`
3. То же для блока тура (секция `bunny_bg-wrapper`) с файлами `tour-*`.
4. Замените скрипт `initBunnyPlayerBackground` кодом из `webflow/bunny-background.html`.
5. Удалите подключение `hls.js` из Head code: потоковое видео на сайте не используется.

### 2. Аудиоплеер
Замените весь код Embed `spotify_embed` в панели плейлиста на `webflow/soundcloud-embed.html`. Внешний вид и плейлист не меняются: SoundCloud подключится, когда посетитель наведёт курсор на иконку плейлиста или нажмёт Play.

### 3. Скрипты в шапке
1. В **Site settings → Custom code → Head code** у подключений GSAP и Lenis добавьте `defer`:
   `<script src="…/gsap.min.js" defer></script>` и т.д.
2. Исправьте тег Draggable: `…Draggable.min.js" defer></script>` (сейчас там нет `>`).
3. Во встроенных скриптах, которые используют `gsap`, `ScrollTrigger`, `SplitText`, `Draggable` или `Lenis`, замените `<script>` на `<script type="module">`: они выполнятся после библиотек и в том же порядке.
4. Шрифт: загрузите Inter Tight в **Site settings → Fonts** как свой (woff2) и уберите его из Google Fonts. Тогда пропадёт блокирующий `webfont.js`. Временный вариант — строка из `webflow/head-code.html`.

### 4. Анимация появления контента (по желанию)
Скрипт `initContentRevealScroll` сейчас не работает из-за ошибки из пункта 3.2. В ускоренной копии он убран, чтобы внешний вид остался прежним. Если исправить тег и оставить скрипт, на сайте появится задуманная дизайнером анимация появления блоков. Решение за вами.

## Проверка
- Главная: видео первого экрана начинается сразу после загрузки страницы, тур — когда до него долистали.
- Плеер: иконка плейлиста → Play → музыка, название трека и обложка подставляются.
